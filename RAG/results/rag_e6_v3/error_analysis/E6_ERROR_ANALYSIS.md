# Διαγνωστική ανάλυση E6-v2 και E6-v3

Η προσθήκη HHEM αλλάζει την ορθότητα 19 γραμμών: 10 διορθώσεις και 9 νέα λάθη, με καθαρό +1. Το μεγαλύτερο υπόλοιπο είναι τα 78 κοινά λάθη. Η ανάγνωση και των 97 περιπτώσεων δείχνει δύο διαφορετικά ζητήματα: πραγματικές απώλειες/μεταβολές σημασίας που οι evaluators συχνά δέχονται, και περιπτώσεις όπου τα κείμενα ή οι ανθρώπινες ψήφοι δεν στηρίζουν εύκολη διάγνωση. Οι δεύτερες δεν επιτρέπεται να μετατραπούν αυθαίρετα σε «λάθος ετικέτες».

**Exploratory, development-only σε επαναχρησιμοποιημένο σύνολο.** Δεν έγινε νέο πείραμα, training, inference, retrieval ή API call. Η ανάλυση αφορά αποθηκευμένες OOF προβλέψεις και δεν αποτελεί ανεξάρτητη αξιολόγηση.

## 3. Απόσταση από το σταθερό threshold

Ορίζεται d=|OOF prediction−0.5|. Πρόκειται για αριθμητική απόσταση από το όριο απόφασης, **όχι βαθμονομημένη εμπιστοσύνη**. Τα bins είναι περιγραφικά, δεν χρησιμοποιήθηκαν για επιλογή ή αλλαγή threshold. Σε κάθε στήλη μοντέλου ο παρονομαστής είναι ο δικός του πληθυσμός που βρίσκεται στο συγκεκριμένο διάστημα.

| d | N v2 | Λάθη v2 / N | N v3 | Λάθη v3 / N |
|---|---:|---:|---:|---:|
| [0, 0.05] | 49 | 15/49 (30.61%) | 51 | 18/51 (35.29%) |
| (0.05, 0.10] | 48 | 20/48 (41.67%) | 48 | 13/48 (27.08%) |
| (0.10, 0.20] | 127 | 26/127 (20.47%) | 115 | 28/115 (24.35%) |
| >0.20 | 337 | 27/337 (8.01%) | 347 | 28/347 (8.07%) |

| Ομάδα | N | Διάμεσο d v2 | Διάμεσο d v3 |
|---|---:|---:|---:|
| both_correct | 464 | 0.268200 | 0.268933 |
| both_wrong | 78 | 0.149800 | 0.160333 |
| v3_corrected | 10 | 0.014667 | 0.028600 |
| v3_new_error | 9 | 0.042933 | 0.032667 |

Στις 19 αλλαγές, 13/19 έχουν d≤0.10 και στα δύο μοντέλα, ενώ 19/19 σε τουλάχιστον ένα. Όμως 54/78 κοινά λάθη του v3 έχουν d>0.10, και 28/78 έχουν d>0.20. Άρα το υπόλοιπο δεν περιορίζεται σε λίγες προβλέψεις που βρίσκονται δίπλα στο threshold. Δεν έγινε sweep ορίου ή υπολογισμός υποθετικής βελτίωσης από άλλο threshold.

Και οι 19 έχουν αναλυτική σημείωση στο παράρτημα. Οι διορθώσεις περιλαμβάνουν τόσο εύλογες παραφράσεις όσο και κυκλικές/γενικές απαντήσεις. ## 5. Μία κύρια επόμενη παρέμβαση — πρόταση, δεν εκτελέστηκε

**Ένα μικρό, προκαθορισμένο block δομικής κάλυψης και σχέσεων reference–hyp**, που θα επισημαίνει παράλειψη κύριας ενέργειας/ορίσματος και μετατόπιση ποσοδείκτη ή σημασιολογικού ρόλου. Αφετηρία είναι τα saved reference/hyp, με τις ίδιες task-specific επιλογές reference. Στόχος δεν είναι να προσθέσει άλλον γενικό neural evaluator, αλλά να εκθέσει στο RF την τοπική διαφορά που χάνεται σε μία συνολική σημασιολογική βαθμολογία.

**Στήριξη από παρατηρήσεις:** all στο HDEV_0452, his/to him στο HDEV_0350, board the ship στο HDEV_0531, remind/remember στο HDEV_0443 και η παράλειψη names στα HDEV_0317/HDEV_0484. **Υπόθεση:** ρητή τοπική/δομική αντιστοίχιση θα μπορούσε να προσφέρει συμπληρωματική πληροφορία ακόμη όταν entailment/consistency είναι υψηλά. Αυτό δεν έχει δοκιμαστεί. Οι ήδη υπάρχοντες NLI2 A/B scores παρέχουν κατεύθυνση, επομένως μια απλή επανάληψη reverse NLI δεν αρκεί ως νέα ιδέα.

**Πρακτικότητα CPU:** token/lemma alignment και λίγα προκαθορισμένα checks λειτουργούν χωρίς νέο μεγάλο encoder. Για σχέσεις υποκειμένου/αντικειμένου θα χρειαζόταν κατάλληλος CPU dependency parser ή σαφώς περιορισμένες επιφανειακές ενδείξεις.
