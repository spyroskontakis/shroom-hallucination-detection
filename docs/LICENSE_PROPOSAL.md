The FactCG adapter's upstream-derived portions retain upstream attribution; the owner's approval covers their own additions. External datasets, model weights and dependency environments are excluded. No additional known unresolved rights conflict was identified within the reviewed distribution. This conclusion relies on the owner's explicit rights confirmation and the documented upstream verification, not on an inference from Git authorship.

The former [draft](MIT_LICENSE_DRAFT.txt) and earlier reports remain historical records and are superseded by the root LICENSE. They do not impose current licensing blockers.

Public Git author name and exact GitHub noreply email still require separate confirmation. Copyright identity is not automatically approval of a Git author identity. See [Git identity preparation](GIT_IDENTITY_SETUP.md). No Git configuration or repository was created.
